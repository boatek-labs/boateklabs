The Problem

A STEM club with no digital home

TARSCO Robotics Club needed a platform that reflected the energy of the club itself — not a static brochure site. We built a full-stack Node.js/Express platform with an animated canvas hero, SVG robotics decorations, and an AI chat assistant for members.

Node.js · Express · LowDB · OpenRouter
The Problem

Manual attendance across six user roles

The Church of Pentecost Huniso District needed a faster, more reliable way to track attendance across a large, multilingual congregation. We built a facial recognition and QR check-in system supporting English, Twi, Ewe, and Ga.

Node.js · Face Recognition · Multi-language
The Problem

Animation tools that don't talk to each other

MotionAI Studio is a canvas-based animation application with AI scene generation from natural language prompts, plus real-time collaboration via Socket.IO — built for creators who want to describe a scene, not hand-animate every frame.

Socket.IO · Canvas · OpenRouter
